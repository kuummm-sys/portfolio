ホームページの「持ち主」は誰？
ドメインとサーバーの名義を確かめておく理由

「前にホームページを作ってもらった会社と連絡が取れない。電話番号を直したいのに、どこから手をつければいいのか分からない」。こうした困りごとの多くは、ドメインやサーバーの名義が制作会社のままになっていることから起きています。この記事では、ホームページを動かしている3つのものと、名義の確かめ方、自分の名義に移すときの順番をまとめます。

ホームページを動かしている3つのもの

ホームページは、次の3つがそろって表示されています。

ものたとえると契約・保管している先自分の手元にないと
ドメイン（◯◯.jp など）住所ドメインの登録サービス更新や引っ越しの手続きが自分でできない
サーバー土地と建物レンタルサーバー会社、または Wix・Jimdo などの作成ツール契約が止まると、ホームページも消える
中身（データ）家具や内装文章・写真・デザインと、管理画面のログイン情報自分で更新できず、引っ越し先に持っていけない

制作会社が契約から設定までまとめて引き受けるときは、手続きを早く済ませるために制作会社の名前で契約することがよくあります。ふだんは問題になりませんが、制作会社と連絡が取れなくなったとたんに、自分では何も動かせなくなります。

自分の名義になっているか確かめる方法

1. 請求や更新の案内がどこから届いているか

ドメインやサーバーの会社から、自分宛てに更新の案内や請求が届いていれば、自分で契約している可能性が高いです。制作会社から「管理費」「保守費」としてまとめて請求されている場合は、制作会社の名義になっていることが多いです。

2. ドメインの登録者を調べる

「.jp」で終わるドメインは、JPRS の Whois（ドメインの登録情報を調べられる公開サービス）で登録者の名前を確認できます。「.com」などは登録者の情報が伏せられていて、外からは分からないことがよくあります。

3. 管理画面に自分で入れるか

ドメイン、サーバー、作成ツールのそれぞれに、自分の ID とパスワードでログインできるかを確かめます。

分からなければ、制作会社に聞いてかまいません。「ドメインとサーバーの契約者は誰になっていますか」「管理画面のログイン情報をいただけますか」の2つで足ります。契約内容の確認として、ふつうに聞いてよい質問です。

名義が制作会社のままだと困ること

  • 制作会社が廃業した、担当者と連絡が取れない。この場合、更新の案内が自分に届かず、気づかないうちにドメインの期限が切れることがあります。ドメインが止まると、ホームページだけでなく、そのドメインのメールアドレスも使えなくなります。
  • 別の制作会社に頼み直したい。ドメインを移すには、今の名義人の協力が要ります。協力が得られなければ、アドレスを変えて作り直すことになります。
  • 保守契約をやめたい。契約の中身によっては、やめるとサーバーごと止まり、データも手元に残りません。

なかでも影響が大きいのは、ドメインの期限切れです。期限が切れてしばらくすると、ほかの人が同じドメインを取れるようになります。名刺やチラシに載せていたアドレスが、まったく別のサイトに使われてしまうこともあります。

名義を移すときの順番

  1. 今の状態を書き出します。ドメイン名、ドメインとサーバーの契約先、それぞれの名義と期限を1枚にまとめておくと、相談するときに話が早く進みます。
  2. 制作会社に名義の変更を頼みます。ドメインは登録者の変更です。サーバーは契約者を変えてもらうか、自分の名義で新しく契約してデータを移します。
  3. ドメインの管理会社も変えるなら、移管の手続きをします。多くの場合、今の管理会社が発行する「認証コード」を、移管先に伝えて進めます。ドメインの種類によって手順が違うので、移管先の案内に沿って進めます。取ったばかりのドメインなど、しばらく移管できない期間があることもあります。
  4. ログイン情報を受け取ったら、パスワードを変えて、自分で保管します。

制作会社と連絡が取れないときは、ドメインの管理会社に直接事情を相談することになります。必要な書類や手続きは会社ごとに違います。

ドメインの期限が近いときは、名義の相談と並行して、更新がきちんと行われるかを先に確かめてください。期限が切れてからでは、取り戻す手間が大きくなります。

これから作るなら、契約前に確認しておくこと

  • ドメインは誰の名義で登録するか
  • 管理画面のログイン情報を渡してもらえるか
  • 保守契約をやめたとき、ドメインとデータはどうなるか（移管用のコードやデータを渡してもらえるか）

3つめは見落とされがちですが、制作会社を替えるときや、制作会社が廃業したときに効いてくるのはこの条件です。

Arpeda（アルペダ）では、ドメインはお店の名義で登録し、契約をやめるときは移管用のコードとサイトのデータをお渡ししています。「今のホームページの名義がどうなっているか分からない」という確認のご相談だけでもどうぞ。
