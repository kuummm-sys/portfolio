アクセス解析、
最低限どこを見ればいい？

アクセス解析（Googleアナリティクスなど）を入れると、たくさんの数字が並びます。全部を理解する必要はありません。小さな事業でまず見るべきは3つです。

1. どのくらいの人が見に来ているか（訪問数）

1日あたり、1週間あたりに何人が見に来たか。まずは絶対数より「増えているか、横ばいか、減っているか」の傾向を見ます。チラシを配った、SNSで告知した、といった動きの後に数字が動いているかを確認すると、何が効いているか分かってきます。

2. どこから来たか（流入元）

見に来た人が、どの経路でたどり着いたか。ざっくり次のように分かれます。

  • 検索（Google・Yahooなど）… 何かを探していて見つけた
  • SNS … 投稿やプロフィールから
  • 直接 … URLを直接入力、ブックマーク、名刺のQRなど
  • 他サイト … どこかに貼られたリンクから

「検索がゼロに近い」なら、検索に出るための整備がまだ、ということです。「SNSばかり」なら、検索の受け皿を強くする余地があります。

3. どのページがよく見られているか

トップページ以外で、どのページが見られているか。料金ページがよく見られているなら、そこにもっと情報を足す・問い合わせボタンを置く、といった手が打てます。逆に、見てほしいページが見られていないなら、導線（メニューやリンク）を見直します。

この3つを、月に1回、数分見るだけで十分です。細かい指標（滞在時間、直帰率など）は、この3つで方向性が見えてから気にすれば大丈夫です。

そもそもの入れ方

Googleアナリティクスと、前の記事でも触れた Search Console は、どちらも無料です。設定にはコードの貼り付けが必要なので、制作会社に頼むか、設定手順を教えてもらうのが早いです。すでに入っているのに見ていない、というケースもよくあります。

数字を見る目的

数字そのものが目的ではありません。「次に何をするか」を決めるために見ます。数字が動かない月があっても、焦らず、打った手と照らし合わせて考えます。

Arpeda（アルペダ）では、アクセス解析・Search Console の設定と、「どこを見て、次に何をするか」の整理に対応しています。まず設定だけでもご相談ください。
