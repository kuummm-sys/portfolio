補助金・助成金で
ホームページ制作費は出る？（一般的な話）

「ホームページを作りたいが、補助金は使えるのか」というご質問があります。制度によっては対象になります。ただし、内容・金額・条件・募集時期は毎年変わり、地域によっても違います。ここでは一般的な考え方と、確認すべき先をまとめます。

この記事は一般的な整理です。実際に使えるかは、その時点の公募要領と、商工会議所・商工会・自治体の窓口で確認してください。Arpeda は補助金申請の代行はしていません。

ホームページ制作が対象になりやすい制度の例

  • 小規模事業者持続化補助金 … 販路開拓の取り組みに使える国の補助金。ホームページやチラシの制作費が対象経費に含まれることがあります。商工会議所・商工会の支援を受けて申請する形式です。
  • 自治体（都道府県・市区町村）の補助金 … 地域独自に、ホームページ制作やIT活用への補助を出していることがあります。「◯◯市 ホームページ 補助金」で調べる、または役所の産業振興の窓口に聞く。
  • IT導入補助金 … 主に業務用のITツール導入向け。単なるコーポレートサイトは対象外のことが多く、ECサイトや予約・顧客管理の機能を伴う場合に検討対象になります。

制度名や内容は年度で変わります。「今年もあるか」「今の条件は何か」を必ず確認します。

対象になりやすい費用・なりにくい費用

対象になりやすい対象外・注意
制作の外注費、初期の構築費毎月のサーバー・ドメイン代（継続費用は対象外が多い）
ECや予約機能の導入（制度による）補助金の交付決定より前に発注・支払いしたもの
撮影・原稿など制作に必要な経費（制度による）汎用のパソコン購入など

申請の一般的な流れ

  1. 使えそうな制度を探す（商工会議所・自治体窓口・公式サイト）
  2. 公募要領を読み、対象・金額・スケジュールを確認する
  3. 事業計画・見積りを用意する（制作会社に見積りを依頼）
  4. 申請 → 審査 → 交付決定
  5. 交付決定の「後」に発注・制作・支払い
  6. 実績報告 → 補助金の入金（後払いが基本）

特に注意したいのは、多くの制度が「交付決定より前の発注・支払いは対象外」で、「補助金は後から入る（立替が必要）」という点です。

相談先

  • お近くの商工会議所・商工会（持続化補助金の相談窓口）
  • 市区町村・都道府県の産業振興・中小企業支援の窓口
  • 中小企業向けの支援サイト（ミラサポplus など）

Arpeda（アルペダ）は補助金申請の代行はしませんが、申請に使う制作の見積り作成には対応できます。「補助金を使う前提で見積りがほしい」というご相談をどうぞ。
