SNSとホームページ、
どう使い分けて連携させる？

「SNSをやっているから、ホームページは要らないのでは」「両方は手が回らない」。SNSとホームページは役割が違うので、うまく分担させると片方の負担が減ります。

それぞれの得意なこと

SNSホームページ
得意なこと日々の様子を届ける・見つけてもらう・気軽なやり取りまとまった情報を置く・検索の受け皿・信頼
弱いこと過去の投稿が流れて探しにくい・料金や場所が埋もれる更新が止まると「動いていない」印象
持ち主プラットフォーム（仕様変更やアカウント停止の影響を受ける）自分（コントロールできる）

連携のさせ方

SNS → ホームページ

  • プロフィール欄にホームページのURLを入れる
  • 「料金・アクセスはこちら」と、ホームページの該当ページに誘導する
  • 予約・問い合わせは、投稿ではなくホームページで受ける

ホームページ → SNS

  • ヘッダーやフッターにSNSのアイコンを置く
  • 「最近の様子はInstagramで」と一言添える
  • 最新の投稿を数件だけ埋め込む（多く貼ると表示が重くなるので数件で）
おすすめの分担は「日々の発信はSNS、動かない情報（料金・場所・サービス内容・予約）はホームページ」です。ホームページの固定情報は、一度作れば頻繁に更新しなくてよいので、負担が偏りません。

両方やる時間がないとき

優先順位をつけます。

  • 近くで探している人に見つかりたい → まずGoogleビジネスプロフィール（無料）と、1ページでもいいのでホームページ
  • ファンを増やして指名で来てほしい → SNSを1つに絞って続ける

SNSを3つも4つも中途半端にやるより、1つを続けるほうが伝わります。
