# Arpeda — 制作実績（ポートフォリオ）

Arpeda（アルペダ）の LP・ホームページ制作ポートフォリオサイトです。

- `index.html` … 一覧ページ
- `01-整体院LP/` … 店舗・予約獲得型LP（デモ）
- `02-SaaS無料トライアルLP/` … BtoB・登録獲得型LP（デモ）
- `03-オンライン講座LP/` … スクール・申込獲得型LP（デモ）

各LPは単一のHTMLファイルで完結しています（画像も埋め込み済み）。

## 掲載内容について

現在掲載しているLPは、制作力をお見せするためのデモです。すべて架空の商材・企業で、
文中の数値・体験談・コメントはサンプルであり、実在の実績ではありません。
実際のご依頼で制作したものは、掲載のご許可をいただいたものから順次追加します。

## 公開方法（GitHub Pages）

このリポジトリを GitHub にプッシュし、Settings → Pages で
「Deploy from a branch」→ `main` / `/(root)` を選ぶと公開されます。
