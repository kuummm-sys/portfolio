## 仕様

- 各LPは単一の `index.html` で完結。**画像はすべてbase64でHTML内に埋め込み済み**（`img/` は元画像の保管用）。
- 外部リソースは Google Fonts のみ。どの環境で開いても表示が崩れない。
- レスポンシブ対応（PC / タブレット / スマホ）。スマホは追従CTAバー付き。
- 写真はフリー素材（Unsplash / 商用利用可・帰属不要）を使用。差し替えなしでそのまま「完成形」として見せられる。
- スクロールアニメーション付き（JS無効でも全内容が表示される）。

## コンプライアンス方針（このポートフォリオ内で徹底したこと）

- **薬機法・景品表示法に触れうる表現を排除**:
  - 効果・効能の断定（「治る」「根本改善」「〇〇が改善」等）は使わない
  - 体験談は「個人の感想」に留め、必ず打消し表示を添える
  - 客観的根拠のない数値（「満足度98%」「〇%が実感」等）は掲載しない
  - 収入・成果の保証と受け取れる表現は使わない
- カウントダウン・「残り〇席」・二重価格などの表示は、**実案件では必ず事実に基づくこと**。デモでは席数などの断定を避け、カウントダウンは締切日からの実カウントに変更済み。
- すべて架空の商材・企業。文中の数値・体験談はサンプル。

→ 実案件では、業種ごとに広告表現のNGワードを確認する。整体・医療・美容・健康食品・スクール系は特に注意。必要に応じて専門家（弁護士・広告審査）に確認する。
